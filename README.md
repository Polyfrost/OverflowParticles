# OverflowParticles

[![Modrinth downloads](https://img.shields.io/modrinth/dt/61g97TVF?style=flat&logo=modrinth&label=Modrinth&color=1bd96a)](https://modrinth.com/mod/overflowparticles)
[![CurseForge downloads](https://img.shields.io/curseforge/dt/1147767?style=flat&logo=curseforge&label=CurseForge&color=f16436)](https://www.curseforge.com/minecraft/mc-mods/overflowparticles)

OverflowParticles gives every particle type its own settings. It only changes what you see.

For each particle you can:

- Hide it completely
- Recolor it by tinting or replacing its color
- Make it up to 5x bigger, or shrink it to half size
- Spawn up to 10x as many
- Fade it out towards the end of its life

Block particles have their own options. You can hide the ones from mining and breaking blocks, and the ones from entities landing.

A few extras:

- Always show crit and sharpness particles, even on normal hits
- "Clean View" hides your own potion particles in first person
- Let particles pass through blocks
- "Static Particle Color" renders particles at full brightness

## Supported versions

- Minecraft 1.8.9 on Ornithe.
- Minecraft 1.21.1-26.3 on Fabric.

OverflowParticles needs [OneConfig](https://modrinth.com/mod/oneconfig) and Fabric Language Kotlin. The Fabric builds also need Fabric API.
